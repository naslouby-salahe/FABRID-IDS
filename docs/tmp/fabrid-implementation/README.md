# FABRID-IDS Implementation Tracking

This folder is the restart ledger for the autonomous implementation goal
defined in `/home/naslouby/Projects/FABRID-IDS/prompt.md`. Read `state.md`
first on every resume.

Files:

- `state.md` — current phase, last/next chunk, blockers.
- `progress.md` — chronological log of completed chunks.
- `decisions.md` — non-obvious scientific/engineering decisions and why.
- `failures.md` — significant failures and their resolution.
- `audit-log.md` — record of matrix audit passes (A/B/C/D from prompt.md section 3).
- `verification.md` — batched verification cycle results (ruff/pyright/pytest).

The canonical requirements ledger is
`docs/FABRID_IDS_Audit_Implementation_Matrix.md`. This folder tracks
*process*, the matrix tracks *requirements*.
